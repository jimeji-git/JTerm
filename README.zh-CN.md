# JTerm

**一套终端工作区，在 iPhone、iPad 和 Mac 之间自然衔接。**

[English](README.md) · [中文](README.zh-CN.md)

[![在 App Store 下载](https://tools.applemediaservices.com/api/badges/download-on-the-app-store/black/zh-cn?size=250x83)](https://apps.apple.com/app/id6780185815)

JTerm 是面向 Apple 设备的原生 SSH 终端与远程工作工具。它把主机、密钥、常用命令、主机映射和个人设备网络信息放进同一套工作流，让你从 Mac 切换到 iPad 或 iPhone 时，少做重复配置，直接继续工作。

JTerm 不要求注册账号；个人工作区通过你自己的 iCloud 账户同步。

## 配置一次，三端复用

- **iPhone：随时处理明确的小任务。** 查看服务状态、阅读日志、确认任务结果或运行收藏命令。终端扩展键盘提供 Esc、Ctrl、Alt、Tab、方向键和常用符号。
- **iPad：更完整的移动工作区。** 利用侧边栏、灵活布局和硬件键盘处理较长会话、主机切换和远程文件。
- **Mac：集中整理与高频操作。** 在键盘优先的工作区中管理多个 SSH 会话、主机分组、密钥、收藏命令、剪贴板资料和主机映射。

## 哪些内容会通过 iCloud 同步

- SSH 主机地址、端口、用户名、分组、排序和跳板机关系
- 密钥记录以及主机与密钥的绑定关系
- 收藏命令和文本收藏，包括别名与分类
- 主机映射配置、可复用变量和当前选择值
- “我的机器”中的设备名称、平台和活动网卡地址

密码、私钥和密钥口令由 Apple Keychain 保护；凭据能否跨设备使用取决于 iCloud Keychain。显示设置按 iPhone、iPad、Mac 三类设备分别保存。

JTerm 同步的是配置和可复用资料，不会把正在运行的 SSH 连接或实时终端画面迁移到另一台设备。

## 增强剪贴板

在 Mac 上，JTerm 可以搜索文本和图片历史、置顶条目、用别名与分类整理文本收藏、优先展示常用内容，并把收藏命令发送到当前终端。

普通剪贴板历史和图片收藏只保留在本机；主动保存的文本收藏及分类可以通过个人 iCloud 同步，在 iPhone 和 iPad 上继续使用。安装可选的 **JTerm Shortcut** 配套程序后，可以在其他 Mac 应用中按 **⌘⇧V** 呼出浮动剪贴板面板。

## 按环境管理主机映射

可以为开发、测试等环境建立有名字的 hosts 配置。你可以整组启用或停用规则，复用 **DEV_IP** 一类变量，为变量保存多个候选值，并在应用前预览最终内容和检查重复主机名。

映射配置和变量会跨设备同步。你可以在 iPhone 或 iPad 上编辑；真正写入 **/etc/hosts** 的操作由 Mac 上的 JTerm Shortcut 完成，首次应用需要管理员授权。JTerm 会保留其管理区块之外的原有内容。

## 我的机器

“我的机器”用于快速回答一个常见问题：**我的另一台设备现在是什么 IP？**

- 查看设备名称、平台，并识别当前设备
- 按网卡查看 IPv4 与 IPv6 地址
- 一键复制地址，用于连接或调试
- 查看资料更新时间和 iCloud 同步状态
- 手动刷新，或在 JTerm 运行期间自动上报变化

它不是局域网扫描器，也不会自动开启 SSH 或公网访问。实际连接仍要求网络可达且目标服务已经开启。设备休眠或应用未运行时，显示的可能是最近一次上报的信息，而不是实时在线状态。

## 终端与远程管理能力

- 兼容 xterm 的终端渲染
- 密码与 SSH 私钥认证
- 多会话并行和断线自动重连
- SFTP 远程文件浏览与传输
- 多级跳板机
- 搜索、文本选择、回滚、主题和字体设置
- 可选 AI 助手：使用你自己的服务商、接口地址、模型和 API Key

## 一套实用的跨设备流程

1. 在 Mac 上整理主机、密钥、分组和收藏命令。
2. 等待 iCloud 同步后，在 iPad 上使用同一套连接资料和常用文本继续工作。
3. 用 iPhone 快速检查服务，或在“我的机器”中查找个人设备地址。
4. 环境变化时，调整主机映射配置；同步到目标 Mac 后先预览，再在 Mac 上应用。
