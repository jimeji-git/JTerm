# JTerm

**A modern SSH terminal for iPhone, iPad, and Mac.**

JTerm keeps your servers and command-line workflows close at hand across Apple devices. It combines a responsive terminal, secure SSH connections, synced host profiles, and an optional AI assistant in a native interface designed for both touch and keyboard use.

[![Download on the App Store](https://tools.applemediaservices.com/api/badges/download-on-the-app-store/black/en-us?size=250x83)](https://apps.apple.com/app/id6780185815)

Learn more at [jterm.jimeji.com](https://jterm.jimeji.com/).

## Highlights

- **SSH everywhere** — connect from iPhone, iPad, or Mac with password or private-key authentication.
- **A real terminal experience** — ANSI colors, full keyboard input, text selection, search, scrollback, and configurable fonts and themes.
- **Built for mobile work** — a dedicated accessory key row puts Esc, Ctrl, arrows, and other terminal essentials within reach.
- **Multiple live sessions** — keep several terminals open and switch between them without losing your work.
- **Reliable connections** — automatic reconnection helps sessions recover when the network changes.
- **Synced workspace** — keep hosts, keys, snippets, and machine information available across your devices with iCloud.
- **AI assistance on your terms** — connect your own compatible provider, endpoint, model, and API key; the assistant can inspect terminal output and help run commands in the active session.
- **Mac-native conveniences** — keyboard shortcuts, a local shell, clipboard tools, Launch at Login, and the optional JTerm Shortcut companion.

## Designed for every Apple screen

On iPhone, JTerm offers a focused host-to-terminal flow that stays comfortable on a small display. On iPad, a split layout keeps hosts and sessions nearby. On Mac, JTerm expands into a keyboard-first workspace with session tabs, local terminal support, search, clipboard history, and quick-access utilities.

## Privacy and control

JTerm does not require a JTerm account. Connection details and secrets are stored using Apple platform facilities, and optional sync uses your iCloud account. AI features use the provider configuration you supply, so you remain in control of where requests are sent.

## JTerm Shortcut for Mac

JTerm Shortcut is an optional companion for features that are not available inside the App Store sandbox, including system-wide clipboard access and applying synced hosts-file profiles. Download it from the [JTerm website](https://jterm.jimeji.com/).
